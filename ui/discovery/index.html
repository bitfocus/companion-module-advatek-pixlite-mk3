Connection help

For local control, keep Companion and the controller on the same IPv4 subnet. Discovery can find controllers outside that subnet; connecting still needs a reachable address. Routed networks need a suitable route and firewall rules.

HTTPS defaults select port 4443 and the Advatek device certificate profile. Selection fills the address and MAC, and preserves the operator password. Reopen connection settings before editing them.

ADAR sends scans to UDP port 49151. Replies return to a temporary port on the Companion computer.

Multicast uses the selected interface. Broadcast fallback follows the computer's routing. If a controller is missing, enter its address manually in Companion.
