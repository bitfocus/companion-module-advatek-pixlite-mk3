## 0.1.0

Initial release.

- Discover PixLite Mk3 controllers using ADAR.
- Control existing SHOWTime scenes, playlists and output modes.
- Adjust pixel and auxiliary intensity, recall static colours, and prepare or mix RGB/W/X channels.
- Display controller state through feedback and variables.
- Include dark and light presets, saved button images and an example workspace.
